1. Pet API

Manage and retrieve pet profiles. Read operations are public; write operations require administrator credentials.

MethodEndpointAuthDescription
GET/api/pets/PublicList all pets (paginated: 6 items per page)
GET/api/pets/<id>/PublicRetrieve details for a single pet
POST/api/pets/StaffCreate new pet profile
PUT/api/pets/<id>/StaffUpdate pet profile
DELETE/api/pets/<id>/StaffDelete pet profile
Example cURL Request:
curl -X GET "http://127.0.0.1:8000/api/pets/" -H "Accept: application/json"
Example JSON Response:

2. Adoption API

Adopters can submit and view their own applications. Administrators can view all and update statuses.
Business Rules Enforced: Rule 1 (Only available pets can be adopted), Rule 2 (No duplicate active applications), Rule 3 (Approval sets pet to Adopted).

MethodEndpointAuthDescription
GET/api/adoptions/User / TokenGet authenticated user's adoption requests (Admins see all)
POST/api/adoptions/User / TokenSubmit new application (Checks Rules 1 & 2)
GET/api/adoptions/<id>/User / TokenRetrieve request detail
PUT/api/adoptions/<id>/StaffUpdate status (Triggers Rule 3: Approved → Pet Adopted)
Example Application Submission Payload:
curl -X POST "http://127.0.0.1:8000/api/adoptions/" \
  -H "Authorization: Token YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"pet": 1, "phone": "+8801712345678", "address": "Dhanmondi, Dhaka", "reason": "Loving home with garden", "previous_pet_experience": true, "message": "Ready to adopt!"}'

3. Search & Filter API

Combine search keywords and multiple filters simultaneously:

Search Keyword:
GET /api/pets/?search=golden
Filter by Animal Type:
GET /api/pets/?animal_type=Dog
Filter by Gender:
GET /api/pets/?gender=Male
Filter by Location:
GET /api/pets/?location=Dhaka
Combined Search, Filter & Pagination:
GET /api/pets/?animal_type=Dog&gender=Male&location=Dhaka&page=2
